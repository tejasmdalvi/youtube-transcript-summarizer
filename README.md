
# 📺 YouTube Transcript Summarizer

A web-based tool to search YouTube videos, extract transcripts, summarize them using Google Gemini (Bard), and translate the summary into multiple Indian languages.

---

## 🚀 Features

- 🔍 Search YouTube videos by keyword
- 📝 Fetch transcript using YouTube Transcript API
- 🧠 AI-powered summary using Google Gemini in English language
- 🌐 Translate summary into Hindi, Marathi, and Gujarati languages
- 📱 Responsive and user-friendly frontend

---

## 🧩 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **AI Model:** Google Generative AI (Gemini-1.5-Flash)
- **Other APIs:** YouTube Data API v3, Deep Translator

---

## 📁 Project Structure

```
├── app.py           # Flask backend handling API and summarization
├── index.html       # Main frontend layout
├── scripts.js       # Frontend logic for video rendering, fetching, translation
├── styles.css       #  Styling for the frontend 
└── README.md
```
